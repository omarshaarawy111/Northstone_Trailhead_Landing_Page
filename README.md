# Northstone Trailhead Landing Page

A responsive product landing page built as part of a front-end assessment for the fictional outdoor brand **Northstone**.

## Live Demo

🔗 https://dev-fictional-university-theme.pantheonsite.io/northstone-trailhead/

Just press on Continue as it is working in sandbox

## Overview

This project recreates the provided design specification using **WordPress** and **Elementor**, with custom CSS and JavaScript to add interactions not available in Elementor Free.

## Features

- Full-width hero section
- Glassmorphism header
- Responsive feature cards
- Interactive product gallery
  - Thumbnail navigation
  - Previous / Next controls
  - Active thumbnail highlighting
  - Fade image transition
- Customer testimonials
- Footer call-to-action
- Responsive layout for desktop, tablet, and mobile

## Tech Stack

- WordPress
- Elementor Free
- HTML
- CSS
- JavaScript

## Custom Development

### Product Gallery
Implemented with custom JavaScript:

- Default first image
- Thumbnail switching
- Previous / Next navigation
- Active thumbnail state
- Fade animation

### Styling

Custom CSS was used for:

- Glassmorphism effects
- Responsive layout
- Gallery styling
- Navigation arrows
- Feature cards
- Footer newsletter
- Mobile adjustments

## Design Specification

The landing page follows the provided specification:

- Hero section
- Feature strip
- Product gallery
- Social proof
- Footer CTA

Brand Colors

- Moss Green: `#3A4A3F`
- Stone: `#E8E3D8`
- Burnt Orange: `#C1622D`

## Mobile Decisions

Since mobile behavior was intentionally unspecified, the following UX decisions were made:

- Feature cards stack vertically.
- Gallery navigation remains accessible with large touch targets.
- Newsletter input stacks above the CTA button.
- Gallery arrows are repositioned for mobile usability.
